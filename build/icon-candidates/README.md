# Icon candidates

The other drafts for the app icon, kept in case it is ever changed. The icon in use is
`build/icon.svg` (draft C: a teal reply bubble holding the llama head).

- `a-llama-and-bubble.svg` - A: the title-bar llama head, large, with a "typing" reply bubble.
- `b-timeline.svg` - B: the dashboard's timeline, requests as queue / load / first token /
  streaming bars.

To switch: copy one over `build/icon.svg` (keep its header comment up to date), then run
`npm run gen:icon`.
